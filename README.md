# BAQS_Processed_Data

A repository for Live NO, NOy, NO2, SO2, NH3, O3 and SMPS Aerosol data from the Birmingham Air Quality Supersite (Birmingham, UK). The available data is pre-ratified but has been through basic processing to flag out-of-spec values.

Live graphs are available at: https://laneew.github.io/BAQS_Processed_Data/

Ratified data is available at: https://dcsbeddows.github.io/baqs_data/
